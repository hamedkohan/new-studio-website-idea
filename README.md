# 20UP Agency Website

This repository contains the source code for the 20UP Agency website. The website is a static HTML and CSS site designed to be a clean and professional online presence for the business consultancy.

## Project Structure

The project is structured as follows:

- `index.html`: The homepage of the website.
- `about.html`: The "About Us" page.
- `services.html`: The "Services" page.
- `case-studies.html`: The "Case Studies" page.
- `contact.html`: The "Contact Us" page.
- `style.css`: The stylesheet that contains all the styles for the website.

## How to View the Website

To view the website, simply open any of the `.html` files in a web browser. The `index.html` file is the main entry point.

## Customization

The content of the website is currently placeholder text and images. To customize the website, you will need to edit the HTML files and replace the placeholder content with your own. You can also customize the styling by editing the `style.css` file.
